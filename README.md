# Agentic SDLC Orchestrator — URL Shortener

A runnable prototype that turns a plain-English requirement into a **reviewable engineering outcome** (code, tests, docs, release
readiness) using a governed, stateful, multi-agent workflow.

**Principle:** agents execute under defined autonomy boundaries; humans own oversight, approvals and final quality.

| | |
|---|---|
| What you run | `python -m orchestrator run core` — greenfield, brownfield and ambiguous scenarios end to end (~4 s) |
| What it produces | a working FastAPI URL shortener (in `runs/<id>/workspace`), its tests/OpenAPI/README/CHANGELOG, and an `ENGINEERING_SUMMARY.md` |
| What makes it different | explicit dependency graph with gates, parallel branches + sync points, human approvals bound to content hashes, policy guardrails the agents cannot bypass, bounded retry/fallback/rollback/safe-stop, tamper-evident audit log, re-planning when upstream outputs change |

## Setup

Requires Python 3.10+ (developed on 3.14). No services, no API keys.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

make test        # 64 orchestrator tests (~12 s)
make demo        # the three required scenarios
make chaos       # five failure drills (retry, policy block + fallback, rollback + safe-stop, denied approval, PII block)
make all         # everything above + aggregate reliability metrics
```

Without `make`: `python -m orchestrator run core|chaos|all|<scenario>` and `python -m pytest`.

### Run the service the agents built

```bash
cd runs/<greenfield-run-id>/workspace            # printed at the end of each run
pip install -r requirements.txt
uvicorn --factory shortener.api:create_app --port 8000
curl -XPOST localhost:8000/api/v1/urls -H 'content-type: application/json' -d '{"url":"https://example.com/docs"}'
```

### Be the human in the loop

```bash
python -m orchestrator run ambiguous --interactive    # you answer the privacy question and approve/deny the design
```

Try answering *"store the full IP address of every visitor"* — the compliance policy (CMP-002) blocks it and the run safe-stops.

### Inspect a run

```bash
python -m orchestrator runs                         # all runs + metrics
python -m orchestrator trace   <run_id>             # full event timeline
python -m orchestrator lineage <run_id> design      # which tasks/artifacts/decisions produced the design
python -m orchestrator verify  <run_id>             # audit hash-chain integrity
python -m orchestrator run brownfield --inject 'test.unit=transient:2'   # inject your own faults (transient[:n] | fail_always | poison)
```

## Layout

```
orchestrator/
  engine.py      stateful DAG engine (parallel exec, retries, fallback, rollback, safe-stop, re-plan)
  graph.py       dependency graph validation / traversal / Mermaid
  store.py       SQLite: versioned artifacts, task state, hash-chained audit log
  policy.py      security / compliance / change-control rules
  toolbox.py     the only door to the workspace: autonomy limits, policy pre-check, undo journal
  gates.py       named entry/exit gates
  approvals.py   human-in-the-loop providers (scripted, interactive)
  metrics.py     success rate, retries, rollbacks, MTTR, latency — derived from the audit log
  reports.py     trace, lineage, engineering summary
  pipeline.py    the SDLC graph + run()
  agents/        requirements, clarifier, explorer, impact, architect, planner, implementer(+safe), tester, scanner, docs, reviewer, release
  catalog/       baseline service + brownfield change sets the implementer agents apply
scenarios/       the 3 required scenarios + chaos drills (data only)
tests/           orchestrator test-suite
```
